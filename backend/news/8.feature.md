Added `workflow_states` to the REST API serialization of every Dexterity object, and to the summaries of catalog results, so an object's state in every workflow of its chain comes back with the object or the listing itself. The key is added by wrapping `plone.restapi`'s `SerializeToJson.__call__` in place, so its folder and collection serializers, and any serializer an add-on derives from them, carry it too. @ericof
